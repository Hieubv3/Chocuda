# Bản xem trước giao diện

Thư mục này để chứa các file HTML xem trước khi cần đối chiếu trực tiếp trong repo. Hiện các file xem trước đang được giữ ở máy thiết kế và có thể bổ sung vào đây sau:

- `1 Trang chu Dich vu Viec lam.html` - trang chủ, dịch vụ cư dân, việc làm (bản máy tính).
- `2 Cac trang con lai.html` - chợ cư dân, gian hàng, BĐS, dự án, tin tức, tài khoản, trang tĩnh và quản trị.
- `3 Giao dien di dong.html` - 12 màn hình di động cho người dùng.
- `4 Quan tri tren di dong.html` - quản trị trên di động.
- `5 Quan tri phan bo sung.html` - các mảng quản trị còn lại.
- `6 Chon khu vuc va du an.html` - luồng chọn vị trí và dự án trước khi vào giao diện chính.

Muốn mở nhanh: tải các file này về cùng một thư mục rồi mở file đầu tiên bằng trình duyệt.
